One-line joke entry for make.fun's One-Line Laugh-Off bounty: a single funny line that lands on a cold read, with no setup notes and no explanation.

> "I gave my AI agent a day off, and it outsourced me." (51 characters)

Chosen from three candidates for the sharpest reversal, the fewest words, and the freshest angle on AI-agent life.

## Run it

```sh
npx tsx main.ts
```

This writes the joke to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).
